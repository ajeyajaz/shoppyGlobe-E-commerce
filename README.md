# 🛒 ShoppyGlobe – E-commerce Application

A modern, responsive e-commerce web application built with **React**, **Redux Toolkit**, and **React Router** 


🔗 **GitHub Repository:**  
https://github.com/ajeyajaz/shoppyGlobe-E-commerce.git

---

## 📌 Project Overview

**ShoppyGlobe** is a basic e-commerce platform where users can:
- Browse products
- Search products
- View product details
- Add/remove items from cart
- Update product quantity
- Checkout and place an order

---

## 🚀 Live Features

- 🏠 Home page with product listing
- Product search
- Product detail page
- Shopping cart with quantity control
- Checkout with address form validation
- Order placed confirmation with auto-redirect
- 404 Not Found page for invalid routes


---

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/ajeyajaz/shoppyGlobe-E-commerce.git

# Navigate to project folder
cd shoppyGlobe-E-commerce

# Install dependencies
npm install

# Start development server
npm run dev
```
